# Project Rules & Guidelines

- **Hindari penggunaan icon magic sparkle / AI**: Jangan menggunakan icon `Sparkles`, `Sparkle`, `Wand`, `Wand2`, dll. untuk dekorasi, AI, ataupun fitur fungsional.
- Gunakan icon yang relevan secara fungsional seperti `LayoutTemplate`, `Palette`, `Layers`, `TrendingUp`, `Star`, `Zap`, atau `Code2`.
- **Minimalkan istilah teknis / jargon developer di UI**:
  - Gunakan bahasa Indonesia yang lugas, mudah dipahami orang awam/pemilik bisnis, dan berorientasi pada manfaat/solusi.
  - Hindari istilah teknis developer seperti `RBAC`, `Spatie`, `Starterkit`, `REST API Endpoints`, `Boilerplate`, `Runes`, `Fullstack`, dsb. pada teks antarmuka, judul modul, menu navigasi, dan copywriting publik.
  - Gunakan padanan fungsional seperti:
    - *Role & RBAC* -> *Peran & Hak Akses*
    - *Media Library (Asset Manager)* -> *Galeri Berkas & Gambar*
    - *Redirect Manager* -> *Pengalihan Tautan*
    - *Audit Log Activity* -> *Riwayat Aktivitas Sistem*
    - *Landing Page Builder* -> *Editor Halaman Utama*
    - *Dynamic Form Builder* -> *Pembuat Formulir Online*
    - *CMS Analytics* -> *Statistik Pengunjung*
