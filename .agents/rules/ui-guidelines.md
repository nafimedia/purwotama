# UI & Copywriting Guidelines

## Larangan Icon AI / Magic Sparkle
- **Hindari penggunaan icon magic sparkle / AI** seperti `Sparkles`, `Sparkle`, `Wand`, `Wand2`, dsb.
- Gunakan icon representatif sesuai fungsionalitas dan domain fitur:
  - **Visual Builder / Landing Page**: Gunakan `LayoutTemplate`, `Layers`, `PanelsTopLeft`, atau `Blocks`.
  - **Branding & Tema**: Gunakan `Palette`, `Brush`, atau `Image`.
  - **Artikel Populer / Trending**: Gunakan `TrendingUp` atau `Flame`.
  - **Artikel Terkait / Konten**: Gunakan `Layers`, `BookOpen`, atau `Newspaper`.
  - **Badge Fitur / Highlight**: Gunakan `Star`, `Award`, `Zap`, `Code2`, atau indikator status dot pulsa.

## Kurangi Istilah Teknis / Jargon Developer di UI
- Gunakan bahasa Indonesia yang ramah pengguna, berorientasi bisnis, dan mudah dimengerti:
  - Hindari penyebutan pustaka/library teknis seperti `Spatie`, `Sanctum`, `TanStack`, `Inertia`, `Runes`, `Tailwind`, dsb. di halaman publik maupun dasbor admin.
  - Hindari jargon teknis seperti `RBAC`, `REST API Endpoints`, `Boilerplate`, `Starterkit`, `Payload`, `CRUD`, `Audit Trail`.
  - Gunakan istilah yang fokus pada hasil dan manfaat (contoh: *Hak Akses Pengguna*, *Keamanan Data*, *Riwayat Aktivitas*, *Ekspor Laporan*, *Pengalihan Tautan*, dsb.).
